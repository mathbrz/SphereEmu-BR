# Community (Discord)

Languages: English | [Italiano](COMMUNITY.it.md) | [Português](COMMUNITY.pt-BR.md)

Ready texts to set up the project's category on Discord. Copy them, fix the repository link and pin them. The channel
names are in English for everyone, the texts exist in three languages.

## Suggested structure (category "Development")

| Channel | Type | What it is for |
|---|---|---|
| `#dev-announcements` | text, only admins write | news, versions, requests for testing |
| `#how-to-contribute` | text, read only | rules and how to take part |
| `#bugs-and-tests` | forum | one thread per problem, with tags: Bug, Test, Idea, Solved |
| `#dev-questions` | text | free talk about the project |

## Message for `#dev-announcements`

> We created a repository for the Sphere BR project: a community base, **not for profit**, that copies the original
> game as closely as possible, using measurements made by players. The repository **contains no game files** and
> there is no public server.
>
> Want to help? Read `#how-to-contribute`. To report a problem, open a thread in `#bugs-and-tests`.

## Pinned message for `#how-to-contribute`

> **What this project is**
> A community test server, made by fans and not for profit. We sell nothing, accept no donations and host no server for
> others. The repository holds no game files (client, models, textures, data). See `DISCLAIMER.md`.
>
> **How to take part**
> 1. Ask for access to the repository with your GitHub user name.
> 2. Read `docs/GETTING_STARTED.md` to run the server on your computer.
> 3. Report problems in `#bugs-and-tests` and send proposals as an issue or pull request on GitHub.
>
> **Rules**
> - Do not post game files, network captures, databases (`sph.db`), logs with a login, or passwords.
> - A change of behaviour needs evidence: a capture of the official server, client data or a measurement. Without it
>   the change is marked "custom" and stays configurable.
> - Respect above all. Portuguese, Italian, Russian and English are all welcome here.

## Frequently asked questions

**Is this legal?** We do not give legal advice. The project distributes no game file, charges nothing and hosts no
public server, and says so in `DISCLAIMER.md`.

**Can I play with friends?** Each person runs the server on their own computer. The project offers no server.

**Can I donate or sell something?** No. The project accepts no money and sells no items.
