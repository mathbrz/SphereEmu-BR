# Community (Discord)

Languages: [English](COMMUNITY.md) | Italiano | [Português](COMMUNITY.pt-BR.md)

Testi pronti per creare la categoria del progetto su Discord. Copiali, aggiorna il link del repository e fissali.

## Struttura consigliata (categoria "Sviluppo")

| Canale | Tipo | A cosa serve |
|---|---|---|
| `#dev-announcements` | testo, scrivono solo gli admin | novità, versioni, richieste di test |
| `#how-to-contribute` | testo, sola lettura | regole e come partecipare |
| `#bugs-and-tests` | forum | un thread per problema, con tag: Bug, Test, Idea, Risolto |
| `#dev-questions` | testo | chiacchiere libere sul progetto |

## Messaggio per `#dev-announcements`

> Abbiamo creato un repository per il progetto Sphere BR: una base della community, **senza scopo di lucro**, che
> imita il gioco originale il più possibile usando misure fatte dai giocatori. Il repository **non contiene alcun
> file del gioco** e non esiste un server pubblico.
>
> Vuoi aiutare? Leggi `#how-to-contribute`. Per segnalare un problema, apri un thread in `#bugs-and-tests`.

## Messaggio fissato per `#how-to-contribute`

> **Cos'è questo progetto**
> Un server di test della community, fatto da fan e senza scopo di lucro. Non vendiamo nulla, non accettiamo
> donazioni e non ospitiamo server per terzi. Il repository non contiene file del gioco (client, modelli,
> texture, dati). Vedi `DISCLAIMER.md`.
>
> **Come partecipare**
> 1. Chiedi l'accesso al repository con il tuo nome utente GitHub.
> 2. Leggi `docs/GETTING_STARTED.md` per avviare il server sul tuo computer.
> 3. Segnala i problemi in `#bugs-and-tests` e le proposte con issue o pull request su GitHub.
>
> **Regole**
> - Non pubblicare file del gioco, catture di rete, database (`sph.db`), log con il login né password.
> - Un cambio di comportamento richiede una prova: una cattura del server ufficiale, dati del client o una
>   misura. Senza, viene marcato come "custom" e resta configurabile.
> - Rispetto prima di tutto. Qui sono benvenuti portoghese, italiano, russo e inglese.

## Domande frequenti

**È legale?** Non diamo consulenza legale. Il progetto non distribuisce alcun file del gioco, non fa pagare nulla
e non ospita un server pubblico, e lo scrive nel `DISCLAIMER.md`.

**Posso giocare con gli amici?** Ognuno avvia il server sul proprio computer. Il progetto non offre un server.

**Posso donare o vendere qualcosa?** No. Il progetto non accetta denaro né vende oggetti.
