## Mensagem para `#dev-announcements`

> Criamos um repositório para o projeto Sphere BR: uma base comunitária, **sem fins lucrativos**, que imita o jogo
> original o mais perto possível, usando medições feitas por jogadores. O repositório **não contém nenhum arquivo
> do jogo** e não existe servidor público.
>
> Quer ajudar? Leia `#how-to-contribute`. Para relatar um problema, abra um tópico em `#bugs-and-tests`.

## Mensagem fixa para `#how-to-contribute`

> **O que é este projeto**
> Um servidor de teste da comunidade, feito por fãs e sem fins lucrativos. Não vendemos nada, não aceitamos
> doações e não hospedamos servidor para terceiros. O repositório não tem arquivos do jogo (cliente, modelos,
> texturas, dados). Veja o `DISCLAIMER.md`.
>
> **Como participar**
> 1. Faça um fork do repositório no GitHub e clone o seu fork.
> 2. Leia `docs/GETTING_STARTED.pt-BR.md` para rodar o servidor no seu computador.
> 3. Relate problemas em `#bugs-and-tests` e propostas por issue ou pull request no GitHub.
>
> **Regras**
> - Não poste arquivos do jogo, capturas de rede, bancos de dados (`sph.db`), logs com login nem senhas.
> - Uma mudança de comportamento precisa de evidência: uma captura do servidor oficial, dados do cliente ou uma
>   medição. Sem isso, ela é marcada como "custom" e fica configurável.
> - Respeito acima de tudo. Aqui são bem-vindos português, italiano, russo e inglês.

## Perguntas frequentes

**Isso é legal?** Não damos conselho jurídico. O projeto não distribui nenhum arquivo do jogo, não cobra nada e não
hospeda servidor público, e deixa isso escrito no `DISCLAIMER.md`.

**Posso jogar com amigos?** Cada pessoa roda o servidor no próprio computador. O projeto não oferece servidor.

**Posso doar ou vender algo?** Não. O projeto não aceita dinheiro nem vende itens.
